# Getting Help

Ops Signals is maintained by volunteers. Help is best-effort, with no guaranteed response time.

## Where to Ask

| You want to... | Go to |
| --- | --- |
| Ask how to set something up or use a feature | [Discussions → Q&A](https://github.com/ramprasadgk9/ops-signals/discussions/categories/q-a) |
| Suggest an idea or discuss a bigger change | [Discussions → Ideas](https://github.com/ramprasadgk9/ops-signals/discussions/categories/ideas) |
| Report a bug you can reproduce | [Open an issue](https://github.com/ramprasadgk9/ops-signals/issues/new/choose) with the bug report form |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md); never in a public issue |
| Report a Code of Conduct problem | [opssignals.conduct@gmail.com](mailto:opssignals.conduct@gmail.com) |

## Before You Ask

- **Check the docs.** Start with [Getting started](docs/getting-started.md) (its
  [Troubleshooting](docs/getting-started.md#troubleshooting) section covers common problems) and the [docs index](docs/README.md).
- **Open Setup check** in the web UI. Each red or yellow row has **How to fix**, and **Copy report** gives a summary without secrets to paste into an issue.
- **Ask the assistant** in the app (Ask Ops Signals). It answers from these docs.
- **Search** existing [issues](https://github.com/ramprasadgk9/ops-signals/issues) and
  [Discussions](https://github.com/ramprasadgk9/ops-signals/discussions).

## What Helps Us Help You

- the Ops Signals version, and whether you run the web UI, the Grafana plugin, Compose or Helm
- your metrics source (Prometheus, Mimir or OTLP)
- what you expected and what happened instead
- relevant backend logs, with tokens and passwords removed
