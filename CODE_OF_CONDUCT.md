# Code of Conduct

This project follows the spirit of the Contributor Covenant.

## Our Pledge

We aim to keep this project welcoming, respectful, and useful for everyone.

## Expected Behavior

- Be respectful and constructive
- Focus on the technical issue
- Assume good intent
- Share credit where it is due

## Unacceptable Behavior

- Harassment or discrimination
- Personal attacks
- Deliberate misinformation
- Disruptive or abusive conduct

## Enforcement

Project maintainers may remove content or contributions that violate this code of conduct.
