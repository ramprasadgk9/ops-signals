# Capability-Driven Questions

## Goal

The question layer maps operational questions to the analyzers and signals that can answer them.

## Model

- Question catalog defines the available questions
- Capabilities define what an analyzer can contribute
- Routing selects the relevant signals for the requested question
- Answer composition stays deterministic

## Current Question Areas

- what changed
- unusual activity
- behavior novelty
- baseline changes
- long-term trends
- service health
- investigation priority

## Historical Similarity

Historical similarity is represented in the product direction, but it should be understood as retrieval assistance rather than a final verdict on cause.
